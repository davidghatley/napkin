# napkin brand files

- `napkin-glyph.svg`: the napkin glyph, a 5x5 pixel folded napkin (a right triangle). Copied unchanged from the kitchen (`secret-sauce/assets/glyphs/napkin.svg`); the landing page draws the same shape.
- `napkin-favicon.svg`: the same glyph for browser tabs, dark ink on light tabs and light ink on dark tabs.
- The canvas top bar draws the same glyph inline in `public/index.html`.

Not napkin's: David's personal "mark" (a 7x7 stem shape, labelled "David Hatley mark" in the portfolio). Never use it for napkin's logo, icon or favicon.
