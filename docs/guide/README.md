# napkin user guide

napkin runs locally from this checkout. It renders React TSX components and saves
explicit edits to their source files. A person and agents can edit through the
same running server.

| Task | Page |
|---|---|
| Start the canvas | [Quickstart](quickstart.md) |
| Learn the terms | [Concepts](concepts.md) |
| Create and draw | [Start a component](start-a-component.md) |
| Edit variants and tokens | [Change every version](change-every-version.md) |
| Set agent permissions | [Connect your agent](connect-your-agent.md) |
| Review simultaneous edits | [Edit together](edit-together.md) |
| Review files and use them in an app | [Keep your files](keep-your-files.md) |
| Check current limits | [Limits](GAPS.md) |

Commands on these pages run from the checkout root. Example destinations must be
empty when initialized. Replace a destination consistently to use your own folder.
