# napkin user guide

napkin is a design canvas where you and an AI agent edit the same component at once. Every change saves to a real file in your project.

> **Status: planned.** napkin is Phase 4 of the roadmap and nothing has shipped. This guide is written as if the product exists, so that it can serve as the spec. Commands, file names and screens are working names. Where the guide needs a decision that hasn't been made, it says so and points to [GAPS.md](GAPS.md).

## What napkin will not do
- It is not a whiteboard. There are no sticky notes.
- It does not copy every Figma feature. It sticks to components.
- It does not host your files. They stay in your project folder.
