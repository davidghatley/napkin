# napkin interface inventory

Every part of napkin's interface, largest to smallest, found from the running app (`src/cli.js open` on the `ss-ds` corpus folder) and then captured as fixtures by `storybook/capture.mjs`. This file is generated by `storybook/generate.mjs` from `storybook/inventory.mjs`; edit the inventory, not this file.

Run it: `npm ci` then `npm run storybook` (http://127.0.0.1:6006, localhost only). Re-capture the fixtures from the live app with `npm run storybook:capture`; check every story with `node storybook/check.mjs`. In the Feedback panel under each story pick keep / change / drop and write a note; it is saved to `storybook/feedback/feedback.json`. The sidebar shows a tick on reviewed stories and a count on items.

Ids are stable: `I` = Level 1 interface, `P` = Level 2 panel, `C` = Level 3 component. A story is named `Current · <state>`; variations are named `Variation NN · <idea>` (see VARIATIONS.md).
